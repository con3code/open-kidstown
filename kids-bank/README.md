# kids-bank — ぎんこう (銀行の管理アプリ)

口座と入出金明細を管理する Web アプリ。運営スタッフ・銀行の大人係が使います。
対面のチャージ・引き出しは Xcratch 銀行アプリ (kt-bank) が担い、
このアプリは残高と履歴の確認・訂正を担います。

## できること

- **口座一覧**: 全口座の残高を一覧 (市民 / 店舗の種別、市民番号つき)。検索対応
- **明細の閲覧**: 口座をクリックすると入出金明細 (チャージ・支払い・お祝い金…) を新しい順に表示
- **残高訂正**: トラブル復旧用。新しい残高を入れると差額が「管理訂正」として自動記帳される (理由メモ必須)
- **明細の追加・編集・削除**: 記帳ミスの訂正 (残高は動かさない)
- **CSV 出力**: 口座一覧 / 口座別の明細 / 全口座の明細

## 使い方

1. アプリを開いてマスターキーを入力
2. 口座一覧が出る。窓口やレジでのお金の動きはすべてここで確認できます

よくある操作:
- **「決済の途中でしっぱいした」と報告が来た** → 取引番号を聞き、買手とお店の明細を確認 →
  足りない分を「残高訂正」で直す (理由に取引番号をメモ)
- **タウン終了後の記録保存** → 「口座CSV」「全明細CSV」

補足: 一覧に「不明」と出る口座は、明細のない残高だけのデータです (通常は現れません)。

## 自分でデプロイする

[../docs/setup.md](../docs/setup.md) の Step 2 参照。要点:

```sh
npm install
npm run dev -w kids-bank           # → http://localhost:5303
cd kids-bank
cp .firebaserc.example .firebaserc
npm run build
npx firebase-tools deploy --only hosting
```
