# kt-sys — システム管理 (タウン運営者専用)

タウンのデータを一括操作するメンテナンスアプリ。**運営責任者だけ**が使います。

## できること

- **タウン統計**: 市民数・口座数・明細数・お店ごとの取引数などを一覧 (リセット前後の確認に)
- **claim の掃除**: 内部の作業データ (採番の席取り記録) の掃除。データには影響しません
- **残高の一括リセット**: 全口座 (または市民のみ / 店舗のみ) の残高を 0 か指定額に設定。
  「明細も削除して初期化」を選ぶと履歴もまっさらに (次回開催で全員 500 えんスタート、など)
- **お店の取引リセット** (お店ごと): 売買記録を全部消して、取引番号を 1 番からやり直す
- **タウン全体リセット**: このマスターキーの全データを消去して最初からやり直す。
  まちがい防止のため「リセット」とタイプしないと実行できません
- **タウン全体をJSONで書き出し / 読み込み**: 全データをファイルに保存・復元できます。
  別のマスターキーのタウンへ読み込めば「タウンの引っ越し」も可能
  (合言葉を変えたいとき・年度をまたいでデータを持ち越したいときに)。
  ダンプファイルには市民の記録がすべて入るので、取り扱いに注意

## 使い方と注意

1. アプリを開いてマスターキーを入力 → 統計が表示される
2. 操作したいカードをクリック → 内容を確認して実行

⚠ **必ず守ること**:
- 操作の前に窓口アプリ (Xcratch) をすべて止める
- 削除は元に戻せない。残したい記録は先に各アプリで CSV 出力しておく
- 「タウン全体リセット」はこのマスターキーで書かれた**すべて**のデータが対象

## 自分でデプロイする

[../docs/setup.md](../docs/setup.md) の Step 2 参照。要点:

```sh
npm install
npm run dev -w kt-sys              # → http://localhost:5304
cd kt-sys
cp .firebaserc.example .firebaserc
npm run build
npx firebase-tools deploy --only hosting
```
