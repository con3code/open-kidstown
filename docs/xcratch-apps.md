# Xcratch 窓口アプリの使い方

子どもが対面業務で使う 3 つのアプリの操作ガイドです。ファイルは
[../xcratch-apps/](../xcratch-apps/) にあります。

| ファイル | 役割 |
|---|---|
| `kt-cityhall.sb3` | 市役所窓口 (市民登録・カード変更/抹消・お祝い金・給付金100・ぜいきん30) |
| `kt-bank.sb3` | 銀行窓口 (残高照会・チャージ・ひきだし) |
| `kt-shop.sb3` | お店レジ (カートに入れて IC カードで決済) |
| `kt-common.sprite3` | 共通部品スプライト (自分でアプリを作る人向け) |
| `dev/kt-common-test.sb3` | 接続テスト用ミニプロジェクト |

## 共通の操作

- **起動**: Chrome で [Xcratch エディタ](https://xcratch.github.io/editor/) を開き、
  sb3 ファイルを読み込んで旗をクリック。マスターキーを聞かれるので入力します
  (マスターキーはどこにも保存されません。毎回入力します)
- **カードリーダー**: PaSoRi を USB につなぎ、「ぱそり」スプライトの Connect 操作で
  デバイスを選びます。**PaSoRi がないときは、カード読み取り中にスペースキーを押すと
  IDm (カード番号) を手入力できます**
- 書き込みに失敗すると「しっぱいしました」と表示されます。ネット接続を確認して
  もう一度やり直してください
- **最初の接続テスト**: `dev/kt-common-test.sb3` を読み込み、kt-common スプライトを
  クリック → マスターキー入力 → 「テストかんりょう!」まで進めば環境は正常です
  (テストで作られた `test` 口座は、ぎんこう Web から削除できます)

## 市役所 (kt-cityhall)

画面のボタンで業務を選びます:

| ボタン | できること |
|---|---|
| とうろく | 新しい市民を登録。市民番号が自動でふられ (1001〜)、カードをかざすと市民証・口座になる |
| カードへんこう | カードをなくした・こわれたとき。ふるいカード (なければ市民番号) → あたらしいカードの順にかざすと、残高ごと引っ越しされる |
| カードまっしょう | カードを使えなくして、市民台帳の状態を「抹消」にする |
| おいわいきん | 金額を入力してカードをかざすと、口座にふりこまれる (給与にも使える) |
| 給付金100 | ボタンを押してカードをかざすだけで、口座に 100 えんふりこまれる (金額入力なし) |
| ぜいきん30 | ボタンを押してカードをかざすだけで、口座から 30 えんの税金をいただく (残高不足はことわられる) |

登録した市民は 市民DB Web (citizen-db) の一覧にすぐ表示されます。

## 銀行 (kt-bank)

| 操作 | 手順 |
|---|---|
| ざんだか照会 | 「ざんだか」ボタン → カードをかざす → 残高が表示される |
| チャージ | テンキーで金額 → カードをかざす → 入金完了 |
| ひきだし | 「ひきだし」ボタン → 金額を入力 → カードをかざす → 出金完了 (残高不足はことわられる) |

- 登録されていないカードは「しやくしょで とうろくしてね」と案内されます
  (口座を作れるのは市役所だけです)
- すべての入出金は明細として記録され、ぎんこう Web (kids-bank) で確認できます

## お店レジ (kt-shop)

1. 起動時にお店番号 (例 `B06`) とマスターキーを入力
2. 商品をクリックしてカートに入れる (個数も選べる)
3. 「おかいけい」→ お客さんのカードをかざす
4. 決済中は「1/5 〜 5/5」の進捗が表示され、完了すると残高が表示される

- 残高不足・未登録カードは決済前にことわられます (お金は動きません)
- **決済の途中で「※〜に しっぱい」と出たら**: 表示された取引番号をメモして
  スタッフに伝えてください。お店POS Web で取引を手入力、ぎんこう Web で残高訂正
  すれば復旧できます (「2/5 カードから しはらい」より前の失敗は、
  お金が動いていないのでそのままやり直せば OK)
- 売上はお店の口座 (`shop.お店番号`) に入金され、取引はお店POS Web に記録されます

## 本番前のリハーサル (通し確認)

1. 市役所: スタッフを 1 人「とうろく」→ おいわいきん 500
2. 銀行: チャージ 300 → ざんだか照会が 800
3. レジ: 80 えんの買い物 → 残高 720
4. Web で突合: 市民DB (台帳・残高) / ぎんこう (明細 4 件+お店の入金) / お店POS (取引 1 件)
5. テストデータはシステム管理 (kt-sys) の「タウン全体リセット」で掃除

## カスタマイズしたい人へ

- 商品・値段・見た目 (コスチューム)・音は Xcratch エディタで自由に変えられます。
  変えてよいのはスプライトの見た目や文言で、**「kt-common」スプライトの中身と
  グローバル変数 `KT_〜` は消さない**でください (クラウド通信の心臓部です)
- 新しい窓口アプリを作るときは `kt-common.sprite3` を読み込むと、
  「せつぞく」「カード読み取り」「残高の増減」「明細の記録」などの機能を
  メッセージ (`KT_せつぞくして` など) で呼び出せます
