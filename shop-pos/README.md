# shop-pos — お店POS (小売店の管理アプリ)

お店ごとの売買記録を管理する Web アプリ。運営スタッフ・お店の大人係が使います。
実際の決済 (カート・IC カード引落し) は Xcratch レジアプリ (kt-shop) が担い、
このアプリは記録の確認・訂正・集計を担います。

## できること

- **お店の登録**: 店舗 ID (例 B06) と店名を登録すると、お店の口座も自動で開設される
- **取引一覧** (お店ごと): 取引番号・日時・品目・個数・金額・決済カード・状態を一覧。
  番号・品名・カードで検索。画面上部に売上合計も表示
- **取引の手入力**: レジが使えなかったときの代替入力
  (**残高は動きません**。お金の訂正はぎんこう Web の「残高訂正」で行う役割分担です)
- **取消 / 編集**: まちがえた取引は「取消 (void)」に。品目や金額の訂正も可
- **CSV 出力**: 1 行 1 品目に展開した売上明細 (Excel でそのまま集計できる)

## 使い方

1. アプリを開いてマスターキーを入力
2. お店を選ぶ (レジアプリが動いていれば、お店は自動で見つかります)
3. 取引はレジでの決済と同時にここへ記録されていきます

よくある操作:
- **開店準備** → 「+ お店を登録」で店舗 ID と店名を登録
- **売上の締め** → 取引一覧を CSV 出力
- **二重決済のとりけし** → 該当取引を「取消 (void)」にし、ぎんこう Web で残高を訂正

## 自分でデプロイする

[../docs/setup.md](../docs/setup.md) の Step 2 参照。要点:

```sh
npm install
npm run dev -w shop-pos            # → http://localhost:5302
cd shop-pos
cp .firebaserc.example .firebaserc
npm run build
npx firebase-tools deploy --only hosting
```
