# citizen-db — 市民DB (市役所の管理アプリ)

市民台帳を管理する Web アプリ。運営スタッフが使います。
対面の窓口業務 (登録・お祝い金など) は Xcratch 市役所アプリ (kt-cityhall) が担い、
このアプリは台帳の確認・訂正・バックアップを担います。

## できること

- **市民一覧**: 市民番号・カード (IDm)・登録日・状態・メモ・残高を一覧。検索と状態フィルタつき
- **市民登録**: 「+ 市民登録」で番号が自動でふられる (1001〜)。IDm は貼り付け入力、空のまま後日発行も可
- **編集**: 行をクリックしてメモ・状態 (有効/停止/抹消)・登録日を訂正
- **カード差し替え**: カード紛失・再発行のとき。新しい IDm を入れると残高ごと引っ越しし、古いカードは無効化される
- **一斉お祝い金**: 「一斉お祝い金…」ボタンで、有効でカード発行済みの全市民に
  指定額 (既定 100 えん) をまとめてふりこむ (進捗表示つき)
- **CSV 出力 / 取込**: 台帳のバックアップと一括登録 (列: 市民番号, IDm, 登録日, 状態, メモ)

## 使い方

1. アプリを開くとマスターキーを聞かれるので入力 (タウンの合言葉。保存はされません)
2. 一覧が表示される。窓口 (Xcratch) での登録も自動でここに反映されます
3. 画面右上の「ロック」で接続を切れます (席を離れるときに)

よくある操作:
- **カードをなくした子への対応** → 該当市民の行をクリック → 「カード差し替え…」→ 新しいカードの IDm を入力
- **タウン終了後の記録保存** → 「CSV出力」

## 自分でデプロイする

[../docs/setup.md](../docs/setup.md) の Step 2 参照。要点:

```sh
npm install                        # リポジトリルートで一度だけ
npm run dev -w citizen-db          # 手元で試す → http://localhost:5301
cd citizen-db
cp .firebaserc.example .firebaserc # プロジェクトIDを自分のものに書き換え
npm run build
npx firebase-tools deploy --only hosting
```
